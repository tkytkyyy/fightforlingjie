# 百炼英雄 · 灵姐争夺战 🥊

**在线玩：** https://tkytkyyy.github.io/fightforlingjie/

16 位勇士单败淘汰，抢灵姐。4 轮：16 强 → 8 强 → 4 强 → 决赛。

## 玩法

1. **自选角色**：16 人各有独门绝技（16 个技能互不重复）
2. **两两分组**：你所在那组由你亲自打，其余组别自动结算，胜者进下一轮
3. **灵姐随机干预**：她会笑、会递水、会皱眉、会喊「嗦他！」——站队看心情
4. **暗中优势**：你选的角色有隐藏加成（战力 ×1.12、暴击 +6%、技能触发 ×1.18、更易被灵姐眷顾），**但不是必胜**
5. **三次保底**：第 1 次夺冠率约 30%，第 2 次约 70%，第 3 次必定夺冠

## 技术

单文件 index.html，17 张头像以 data URI 内嵌，零依赖、可离线。原生 ES5 JS（兼容微信内置浏览器），动效全部是 CSS @keyframes。
数值经 16000 场模拟校准：各角色胜率 37%~59%，对局中位 7 回合。

## v2 战斗表现

- **近身肉搏**：一半角色（Jackie / 一锤 / 兰尼 / 土豆 / 大炮哥 / 木 / 阿祖 / 鱼）会真的**冲到对手面前贴脸连打**——突进 → 连击 3~4 下（暴击 4 下）→ 把对手**击退** → 回位。带残影、撞击星芒、白闪、武器挥动。
- **远程**角色（纳鲁托 / 老君 / 老夜 / 超7 / 诱惑 / 小郎君 / 老白 / 回忆）原地放气刃 / 飞吻 / 账单，命中也会把人打退一小步。
- **人物**：每人一套专属战袍配色（16 色）、发型、武器（🥊🔨📣🪵🍥🧪🗡️💰💐🃏🐟…），还会冒表情（发力 😤 / 挨打 😵 / 取胜 😎）。
- **场景**：擂台围栏、飘落花瓣、观众欢呼、灯光扫射；**16强 / 8强 / 4强 / 决赛**四套配色（紫夜 → 蓝夜 → 赤红 → 金）。
- **打击感**：命中星芒 + 白闪 + 火花四散 + 屏震 + 影子撑开；暴击追加光爆。
- **细节**：战前 VS 入场 + 挑衅台词、**COMBO ×N** 连击计数（3 连起观众欢呼）、**残血时屏幕红边脉动**、灵姐站在场边当裁判（气泡会吐槽）。

## v3 精致化

- **人物改成 SVG 立绘**：不再是方块拼接。有描边、渐变上衣、腰带+金扣、拳套、靴子、脖子、发型，头发颜色从战袍色推导；头仍是真实头像照片（HTML img 盖在 SVG 上，兼容性最好）。
- **格斗连招**：每人一套专属连招，一次肉搏三招不重样——。Jackie 是直拳→勾拳→上勾，一锤和土豆是三连抡砸，纳鲁托和超7 带踢击，老夜是手刀接踢。
- **终结技**：把人打空血的瞬间——画面压暗、播放速度降到 1/2.4 的慢镜头、金色 FINISH 大字、三连光爆 + 屏震，然后对手才倒地。
- **场景**：远景城市剪影（clip-path 天际线）、两层观众席、**举着应援牌的观众**（暴击时一起晃）、聚光灯、椭圆擂台垫、**两根角柱 + 三根绳索**、飘落花瓣、地面反光。
- **残血表现**：血条低于 32% 时角色**发抖**、头顶**冒汗**；低于 28% 屏幕红边脉动。
- **赢家庆祝**：胜者举双手上下弹跳 + 😎。

## v4

- **修复快进**：根因是按钮被绑定了两次 click 监听，点一下等于切换两次，永远回到关闭状态（改用  时重复 δÌ滻Îļþ 导致）。现在快进是全局状态，按钮会高亮显示「▶▶ 快进中」，跨战斗保持。
- **快进更彻底**：不只是日志变快，**所有动画时长也乘 0.3**（突进、连打、击退、特效一并加速），所以是真的变快，不是只有文字刷得快。
- **新增跳过 ⏭**：战斗中点一下立刻结算，血条直接跳到最终结果，马上出胜负页。
- **功夫片式格斗（5 种编排，随机触发）**：
  1. **连招** combo — 按角色专属套路打 3~4 下（暴击 4 下）
  2. **乱拳** flurry — 6 下急速交替 + 放射速度线
  3. **对拳** clash — 双方同时冲上来硬碰硬，中央爆火花，一起弹开
  4. **挑空** launch — 上勾拳把对手打上天，转体后**砸回地面**：扬尘 + 地面冲击波 + 镜头推近
  5. **踢飞** kickaway — 一脚把对手横着踢飞出去，撞地扬尘
- 新特效：放射速度线、扬尘、地面冲击波（椭圆扩散）、镜头推近（arena 短暂放大）。
